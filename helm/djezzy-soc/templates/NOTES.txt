5. **Next Steps**

   a. Configure secrets using sealed-secrets:
      ```bash
      kubeseal --format yaml < secrets-template.yaml > sealed-secrets.yaml
      kubectl apply -f sealed-secrets.yaml
      ```

   b. Verify all pods are running:
      ```bash
      kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/name=djezzy-soc
      ```

   c. Check component health:
      ```bash
      kubectl exec -it deployment/{{ include "djezzy-soc.fullname" . }} -n {{ .Release.Namespace }} -- curl localhost:{{ .Values.service.port | default 8080 }}/health
      ```

   d. Access Grafana dashboards at the monitoring URL above.
